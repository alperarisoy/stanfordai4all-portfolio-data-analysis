# Portfolio Analysis Mini Project

This is a small Python learning project about finance, price data, returns, volatility, and simple portfolio analysis.

The goal was to understand how a few different assets can be compared using basic return and risk calculations.

This is not a professional investment model. It is a simple practice project.

## What the code does

* uses sample price data
* calculates daily returns
* compares average daily return
* compares daily volatility
* creates a simple weighted portfolio
* prints the final portfolio result

## How to run

```bash
python portfolio_analysis.py
```

## Notes

I looked at financial websites and market data pages to understand how asset prices and daily changes are usually shown.

In this version, I used sample data directly inside the Python file so the project can run easily without external files.
