# Project Notes

## Why I made this

I am interested in finance and data analysis. I wanted to try a small project where I could use Python with price data.

The main thing I wanted to understand was:

- how to read price data
- how to calculate daily return
- how to compare different assets
- how volatility changes the result
- how portfolio weights affect the final return

## Data note

I checked financial websites and market data pages to understand how prices, daily change, and asset movements are shown.

In this version I used sample data because it is easier to share.

## What I learned

Raw prices are not always enough. Calculating returns makes comparison easier.

Volatility is also important because two assets can have similar returns but different risk levels.

The portfolio result changes when the weights change.
